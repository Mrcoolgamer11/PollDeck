# Rechtstexte für PollDeck

Vorlagen für **Impressum** (`impressum.txt`) und **Datenschutzerklärung** (`datenschutz.txt`), passend zu den Datenverarbeitungen von PollDeck (Cookies, Geräte-ID, Logs, Konten, Mailversand).

1. Alle Platzhalter in `[eckigen Klammern]` ausfüllen bzw. nicht zutreffende Absätze löschen (z. B. SSO).
2. Text im Admin-Bereich unter **Einstellungen → Impressum & Datenschutz** einfügen und speichern.
3. Die Texte erscheinen dann unter `/impressum` und `/datenschutz` und werden automatisch verlinkt.

Hinweis: Die Vorlagen sind keine Rechtsberatung. Bei kommerzieller Nutzung (z. B. bezahlte Nachhilfe) oder im Auftrag einer Schule lieber von einer fachkundigen Stelle prüfen lassen.
